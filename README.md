# D208 – Predictive Modeling

**WGU Master of Science in Data Analytics**

## Overview
Built predictive models to forecast outcomes from healthcare and telecom datasets. Covered both continuous and binary prediction using multiple linear regression and logistic regression.

## Tasks
### Task 1 – Multiple Linear Regression
- **Research question:** To what extent can patient characteristics predict hospital readmission costs?
- Selected and engineered predictors from a medical dataset
- Tested assumptions: linearity, multicollinearity (VIF), normality of residuals
- Interpreted coefficients and evaluated model fit (R²)

### Task 2 – Logistic Regression
- **Research question:** Which customer attributes predict churn (yes/no)?
- Built a binary classification model on telecom churn data
- Evaluated model using accuracy, confusion matrix, and odds ratios
